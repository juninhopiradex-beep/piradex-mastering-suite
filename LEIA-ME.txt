MASTERING SUITE by Piradex — v1.0.1

═══ NOVO MÓDULO: VOICE LAB ═══

Tab própria entre ANÁLISES e STUDIO PRO.
Auto-Tune para voz isolada (stem) com modo SNAP TOTAL.

PIPELINE:
1. CARREGAR STEM
   • Drop zone para WAV/MP3/FLAC
   • Decode via Web Audio API
   • Mostra duração + sample rate + canais

2. ANALISAR
   • Pitch tracking janela-a-janela (FFT 2048, hop 512)
   • Autocorrelação normalizada + refinamento parabólico
   • Resolução: ~0.1 semitons sub-amostra
   • Detecção de escala Krumhansl-Schmuckler (12 maior + 12 menor)
   • % notas dentro/fora da escala detectada

3. APLICAR AUTO-TUNE (offline phase vocoder)
   • Para cada janela calcula shift = target_escala - actual
   • Se nota está fora da escala, escolhe a vizinha mais próxima (±6 semi)
   • SNAP STRENGTH 0-100% controla quão forte é o pull
   • RETUNE SPEED filtra os shifts (0ms = T-Pain robotic, 100ms+ = natural)
   • Phase vocoder por janela com shift variável:
     - FFT do sinal janelado (Hann window)
     - Pitch shift no domínio espectral via bin remapping
     - Phase unwrapping para preservar coerência
     - Resynthesis via IFFT + overlap-add
   • Duração preservada exatamente

4. A/B PLAYER
   • Toca original / auto-tuned / stop
   • Piano roll mostra ANTES (cinzento) vs DEPOIS (rosa)
   • Fundo verde marca notas da escala detectada

5. EXPORT
   • WAV 16-bit PCM (sem deps externas)
   • MP3 (placeholder — precisa de lamejs)
   • "Enviar para MASTER" → usa o buffer auto-tuned na chain master

═══ HONESTIDADE SOBRE LIMITAÇÕES ═══

• Funciona MELHOR com voz isolada limpa (sem instrumentação)
• Voz com muita reverb pode dar pitch tracking instável
• Voz rouca/sussurrada: confidence baixa, pode falhar bins
• Formant shift NÃO é preservado (pitch shift "puro" pode fazer voz
  soar Mickey Mouse em shifts grandes)
• Para shifts pequenos (<3 semi) o resultado é excelente
