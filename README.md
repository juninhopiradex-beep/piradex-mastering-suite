# 🎛️ Piradex Mastering Suite

Software de masterização de áudio com IA integrada, spectrum analyser em tempo real e presets dedicados a géneros africanos e urbanos.

## 🎵 Presets incluídos

| Preset | Descrição |
|--------|-----------|
| **Kizomba** | Graves quentes, mids suaves — sensualidade e groove |
| **Kuduro** | Kick agressivo, muito punch — energia máxima de dança |
| **Zouk** | Graves profundos, stereo amplo — romantismo |
| **Gzouk** | Fusão Zouk + Ghetto — groove urbano |
| **Semba** | Dinâmica preservada — alma angolana |
| **Afro-House** | Sub pesado, percussão afiada — dancefloor |
| **R&B** | Voz no topo, produção polida e cinematográfica |
| **Afrobeats** | Groove colorido — loudness radiofónico |

## ✨ Funcionalidades

- **Spectrum Analyser** em tempo real com gradiente arco-íris
- **VU Meters** L/R com animação fluida
- **6 Macros** arrastáveis: CLEAN, BASS, LOUD, WIDE, PUNCH, FOCUS
- **RE-MASTER** — botão de masterização com IA
- **⚡ MASTERING PIRADEX ⚡** — modo turbo com boost total
- **Bypass** rápido
- **SOURCE** — carrega qualquer ficheiro de áudio

## 🚀 Como usar

1. Abre o `index.html` no browser
2. Escolhe o preset do género musical
3. Carrega o teu áudio com o botão **SOURCE**
4. Ajusta os macros arrastando os knobs
5. Clica **RE-MASTER** para aplicar a IA
6. Para o turbo máximo: **⚡ MASTERING PIRADEX ⚡**
